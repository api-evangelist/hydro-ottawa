# Hydro Ottawa

> Hydro Ottawa Holding Inc. is a private corporation wholly owned by the City of Ottawa and the parent of Hydro Ottawa Limited, the regulated local distribution company that delivers electricity to roughly 372,000 customers in Ottawa and Casselman, Ontario. Its only API obligation comes from Ontario Regulation 633/21 (Energy Data) under the Electricity Act, 1998, which compels covered Ontario distributors to implement Green Button Download My Data and Connect My Data to the NAESB REQ.21 ESPI v3.3 standard and certify with the Green Button Alliance. Hydro Ottawa operates two live Green Button surfaces but publishes no base URI, no API reference and no first-party specification.

Generated by API Evangelist from the Hydro Ottawa provider profile. Hydro Ottawa does not publish an llms.txt of its own (https://hydroottawa.com/llms.txt returns HTTP 404 as of 2026-07-27).

## Important caveats for an agent

- There is **no published Hydro Ottawa API base URL**. Do not guess one. The ESPI base URI is disclosed only after a private third-party onboarding process.
- The OpenAPI in this profile is **authored by the Green Button Alliance, not by Hydro Ottawa**. It describes ESPI 4.0 and its `servers[]` point at the GBA sandbox, while Ontario mandates ESPI v3.3. It is included as the family contract, not as Hydro Ottawa's service.
- Access is **gated by application approval**: complete Hydro Ottawa's onboarding, then test and certify with the Green Button Alliance. There is no self-serve signup, no sandbox, no API key form, no pricing page and no rate-limit document.
- Hydro Ottawa publishes **no open market, grid, generation or outage data as a product**.

## APIs

- [Hydro Ottawa Green Button Connect My Data (CMD) API](https://hydroottawa.com/en/residential/rates-billing/track-your-usage/green-button): OAuth-authorized, machine-to-machine access to a consenting customer's smart meter interval consumption and billing data in NAESB REQ.21 ESPI XML. Mandated by O. Reg. 633/21. Base URI unpublished.

## Specs

- [Green Button API Documentation (ESPI 4.0)](https://raw.githubusercontent.com/api-evangelist/hydro-ottawa/refs/heads/main/openapi/hydro-ottawa-green-button-espi-openapi.yml): OpenAPI 3.0.0, 7 read operations over ApplicationInformation, Authorization, UsagePoint and Bulk batch transfer. Harvested verbatim from the Green Button Alliance.

## Docs

- [Green Button at Hydro Ottawa](https://hydroottawa.com/en/residential/rates-billing/track-your-usage/green-button): what Download My Data and Connect My Data provide, formats, intervals and the 24-month window.
- [Green Button and third-party registration](https://hydroottawa.com/en/accounts-services/services/green-button/green-button-and-third-party-registration): the two-step requirement placed on integrators.
- [Third-party onboarding application](https://ottawaonboarding.savagedata.com/): the live registration application, operated by Savage Data Systems.
- [Customer Green Button authorization portal](https://hydroottawa.savagedata.com/Connect/Authorize): where a customer completes the authorization the third party initiates.
- [Green Button Alliance testing and certification](https://www.greenbuttonalliance.org/testing): the certification step Hydro Ottawa requires.
- [Request additional electricity meter data](https://hydroottawa.com/en/accounts-services/services/request-additional-electricity-meter-data): human form for data older than 24 months.

## Regulation

- [Ontario Regulation 633/21 (Energy Data)](https://www.canlii.org/en/on/laws/regu/o-reg-633-21/latest/o-reg-633-21.html): the instrument that compels Green Button in Ontario.
- [OEB staff guidance for implementation of Green Button](https://www.oeb.ca/sites/default/files/OEB-Staff-Guidance-for-Implementation-of-Green-Button-20211101.pdf): the Ontario Energy Board's implementation guidance.
